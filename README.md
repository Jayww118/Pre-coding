# 零件解析台前端原型

一个可直接运行的纯前端原型（HTML + CSS + JavaScript），使用 mock 数据模拟“图纸文件解析为零件数据”的完整交互流程。

## 功能覆盖

- 候选零件分组展示
  - 默认按系统判断分组（同零件多图纸合并为一组）
  - 可切换为关闭系统分组（每个文件单独成组）
- 分组校验与修正
  - 合并多个候选零件
  - 拆分候选零件（移出文件后生成新零件）
  - 文件在零件间移动
- 主图确认 / 修改
  - 每组可指定 1 张主图
  - 默认按优先级自动选主图：3D > PDF > 2D
- 异常与风险提示
  - 缺主图时显示风险提示
- 自动填充零件信息
  - 表单字段自动填充（识别失败则留空）
  - 零件名默认主图文件名
  - 支持字段：规格尺寸、材料、工艺、表面处理、热处理、表面粗糙度、最小公差、技术要求
- 完善信息后确认入库
  - 点击确认后进入“零件详情页（原型）”展示

## 页面元素

页面包含：零件缩略图、ICON、按钮、表单、图纸列表、CheckBox 选框。

## 本地运行方式

### 方式 1：直接双击

直接打开 `index.html` 即可。

### 方式 2：本地静态服务（推荐）

在项目目录执行：

```bash
python3 -m http.server 5173
```

然后浏览器访问：

```text
http://localhost:5173
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：样式与布局
- `script.js`：mock 数据与全部交互逻辑
